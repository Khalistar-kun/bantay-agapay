Bantay-Agapay for Android (Android 8.0 or newer).

Download `Bantay-Agapay.apk` below and open it on your phone to install.
Android may ask you to allow installation from your browser or Files app.

The app connects to the existing school backend and Supabase database. It does
not contain demo records or embed database administrator credentials.
Camera and location permissions are requested when needed.

This first APK connects through a temporary HTTPS tunnel to the school server
running on the developer's computer. That computer and the tunnel must remain
running. If the tunnel address changes, enter the new HTTPS address using the
app menu → School server. A permanent host has not been configured yet.

This is a directly installable test APK, signed with an Android debug key.
For Play Store distribution, configure a private release signing key.
